GETTING STARTED

Same phone app.

Still adds screening alongside your dialer. It does not replace it.

    Open Home in Still and complete setup. Only one call-screening app can be active at a time.

A LITTLE HELP

Still, explained.

Read the privacy policy ↗
Does Still automatically identify spam?

Still blocks using the contacts and prefix rules you choose. It does not look up callers in a cloud spam database. A rule can block a legitimate caller too, so choose your rules carefully.

Why did a call get through?

Check the call-screening role, pause state, Prefix mode and the matching rule. Hidden caller IDs are not evaluated. Saved contacts stay allowed unless you opt into applying prefixes to them. Failed contact lookups and screening timeouts allow the call.

Can I choose which SIMs to protect?

SIM controls require Still 1.8 or later on Android 12+. Choose All SIMs, one active SIM/eSIM, or a custom combination in the app. The widget cycles All SIMs, individual active SIMs and your saved custom selection. Detection is experimental: unclear receiving-SIM state allows the call. If a selected SIM becomes unavailable, remaining custom SIMs stay protected; if none remains, Still falls back to another available SIM or All SIMs when none is active. Available features depend on your installed version.

How do I import or share prefixes?

Use Import to choose a prefix JSON file, or open an attachment with Still. Review entries before saving; duplicates are skipped and existing rule switches are preserved. New entries start off unless you choose to enable them. Export shares prefixes only, with a recipient you choose.

Which permissions does Still need?

Contacts access is optional for the tester and saved-contact rules. Phone access is optional for SIM selection on Android 12+. All SIMs needs no Phone access. Notification permission is optional for the control card. Still has no Internet, SMS, storage or system call-log permission.

How do I remove my data?

Clear blocked-call history in Calls, remove prefixes in Home, or clear Still’s storage in Android Settings. Exported files must be deleted in the receiving app or folder.
